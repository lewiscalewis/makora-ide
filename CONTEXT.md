# MakoraIDE — Auto-contexto para retomar el trabajo

Última actualización: 2026-08-21. **LEER ESTE ARCHIVO PRIMERO al retomar.**

## Dirección actual (delegada al agente, 2026-08-20)

El usuario delega la dirección técnica del proyecto al agente (director técnico): el agente decide diseño, refactorización y rumbo, actualiza el plan en `docs/opencode-benchmark.md` conforme implementa, y el usuario prueba/audita y da feedback. Trabajo activo: **ola P0 del plan de adopción opencode**. Regla de gobierno: cualquier decisión de diseño relevante → ADR nuevo en `docs/decisions.md` + actualizar este archivo.

## Qué es este proyecto

Prototipo de IDE de escritorio (Windows first, luego macOS/Linux) orientado EXCLUSIVAMENTE a desarrollo agéntico: el usuario conecta su modelo vía API key; el IDE gestiona cómo el modelo interactúa con herramientas y optimiza tokens de entrada/salida al máximo matemático/algorítmico posible sin degradar razonamiento. Nombre: **MakoraIDE**.

El fallo de "cards con errores" era el workspace vacío: ahora `effective_folders()` en Rust usa el home dir como workspace por defecto, y `write_file` crea directorios padre.
- **bash del agente = script .bat temporal (Windows) — ADR-038 (2026-08-21):** `cmd /C "<comando>"` manglingaba comillas internas (`\"` no es escape para cmd) → PowerShell recibía el script como string y lo IMPRIMÍA sin ejecutarlo (`exit: 0` sin salida); además la salida OEM (cp850) con acentos era UTF-8 inválido y `BufRead::lines()` abortaba silencioso. Ahora `write_bat_script()` escribe `@echo off` + `chcp 65001 >nul` + comando + `exit /b %errorlevel%` a `%TEMP%\makora_cmds\*.bat` y ejecuta `cmd /C "<ruta>"` (sin comillas internas en argv → cero mangling; el .bat parsea como tecleado). Se borra tras terminar (incl. cancelación/timeout con `taskkill /T /F`). Linux: `sh -c`. **Compactación wire-only:** el resumen LLM de historial SOLO se inyecta en el wire que ve el modelo (`wire_prefix` + `msgs[wire_tail_start..]`); la UI/persistencia/checkpoints conservan SIEMPRE el historial completo (antes `msgs = compacted` borraba los mensajes del chat del usuario). 62 tests Rust.
- **Sanitización en streaming — ADR-039 (2026-08-21):** `StreamSanitizer` en `gateway.rs` (OpenAI-compat Y Anthropic): los deltas de texto salen al frontend YA saneados (bloques de tool-syntax cerrados se eliminan al instante; el primer tag abierto sin cerrar se retiene hasta que cierra; colas parciales `<inv`/`<|` retenidas; tokens `[toolu_bdrk_*]`/`<|python_tag|>` al instante). Evento `chat-text-final`: al cerrar el turno final el gateway emite el texto completo saneado y `sessionStore` lo usa como autoritativo (corrige acumulado + transcript). Anthropic ahora también extrae/sanea tool-syntax embebida. La limpieza final es insensible a mayúsculas y también borra `thought|thinking|reasoning` y marcadores de tokens (transcript limpio). **El `thinking-delta` (reasoning) también se sanea** con un segundo `StreamSanitizer` (el `reasoning_content` crudo se conserva solo para el eco que exige DeepSeek) y `ThinkingDropdown` aplica `formatResponse`. Directiva 9 del skill base: gestión de errores de herramientas (reintentar, nunca mostrar sintaxis). Los fallos de tools ya no rompen la respuesta NI en streaming. **Refactor ADR-046 (2026-08-21):** la lógica se movió a `output_sanitizer.rs` (única fuente de verdad): `StreamFilter` (streaming) + `extract_embedded_tool_calls` (final) comparten `strip_closed_blocks`; se añade bloque HTML-escaped y `tool_use`/`im_start`/`im_end`; `gateway.rs` fusiona tool-calls nativas + extraídas. 74 tests Rust + 64 vitest.
